# 🛒 Blinkit Sales Dashboard

An interactive Power BI dashboard designed to analyze key sales metrics, product performance, and customer purchasing trends for Blinkit.

## 📌 Project Overview

This project provides an end-to-end data analysis solution using Power BI and Excel to help business stakeholders make data-driven decisions.

* **Objective:** Evaluate overall revenue, outlet performance, and product category trends.
* **Tools Used:** Power BI, Microsoft Excel, DAX (Data Analysis Expressions)

---

## 📊 Key Insights & Features

* **Revenue Metrics:** Track total sales, average order value (AOV), customer ratings, and total items sold.
* **Product Performance:** Categorization of top-selling vs. low-performing inventory items.
* **Outlet Analysis:** Breakdown of sales performance across different outlet types, locations, and establishment years.
* **Interactive Filters:** Dynamic filtering by item type, outlet size, and location tier.
